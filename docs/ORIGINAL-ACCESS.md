# G8 — offline original-source access gate (synthetic-only)

**Status: source-only prototype. Release blocked.** This is not a remote ChatGPT connector, an authentication provider, a production audit system, a secure sharing service or authorization for private data migration. G7's raw decryptor remains a trusted offline primitive, and must never be directly exposed over HTTP/MCP.

`src/archive-access.mjs` composes that primitive with a trusted, operator-provisioned original-source registry and explicit per-principal scope grants. A caller supplies only its high-entropy credential, original Notion ID and requested scope. The gate resolves the encrypted file, SHA-256, scope and decryption secret from trusted configuration, **not from the request**. Credentials are compared as SHA-256 hashes in constant-time operations; they must be randomly generated, never human passwords. An independent 32-byte HMAC key pseudonymizes source IDs and principal IDs in audit events.

Audit behavior: a durable audit callback is REQUIRED; a read is blocked if authorization logging fails. Before releasing original text, the gate checks the decrypted body against the registered ID, scope, UTF-8 byte length and SHA-256, then requires another successful audit entry. Denied access is audited. A protected local JSONL sink is provided for synthetic demonstration: it writes only pseudonymized access metadata, fsyncs each line, requires a 0600 regular file, and stops admitting reads if logging is full or fails. The log is **not encrypted, cryptographically tamper-evident or suited to regulated data**. It is bounded at 1 MiB maximum and refuses further reads when full instead of truncating history.

Local operator revocation is currently **in-process only**, and would be lost on process restart if old grants were reloaded. Time-based expiry is also enforced. A real production authority must persist revocation and grant changes securely, rotate credentials, audit permission changes, and implement identity verification, request throttling, data minimization and independently reviewed key custody. This module adds **no** route to the current local server. No actual Notion originals, secrets, clinical/family content or production database are used in the tests.

The active Knowledge SQLite, FTS and WAL remain plaintext. The existence of an encrypted source capsule does not make the live wiki safe for private production use. Notion remains authoritative; complete source export reconciliation, production identity, live encryption, authenticated access and independent restore must all pass before an owner-approved per-scope cutover.
